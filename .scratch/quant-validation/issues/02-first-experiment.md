## Comments

### 2026-10-15 — 首个实验建议（待用户选择）

建议单市场 BTC/USDT 现货、1 小时频率、单一趋势规则作为 tracer bullet：已完成 K 线收盘价高于最近 20 根已完成 K 线收盘价均值时目标为持有，低于或等于时为空仓；只在目标状态变化时模拟交易。不开杠杆、不做空、不跨所，参数先固定，不搜索最优参数。

研究假设是该规则能否在扣除成本后，以减少持仓时间为代价改善下跌阶段表现；它是待检验假设，不是已知盈利优势。对比同一时间区间、同样成本口径的买入持有与现金基准，记录净收益、回撤、换手、持仓时间及成本。

第一周以历史回放跑通链路，同时进入实时公开行情的本地模拟；只使用完成 K 线产生信号，在信号之后的可用价格模拟成交。历史仅有 K 线时，下一根开盘价加成本是近似，必须标明与实时可成交报价的差异。不能使用出信号当根的收盘价假设成交，也不能把一周运行或一次正收益当作盈利证明。

先冻结规则并保留后续未参与选参的数据检验；Agent 后续改策略须保留实验版本和探索记录，不能覆盖失败结果。具体数据跨度、仓位与成本假设待最小实验范围确定后填写，不启动大规模参数搜索。

界面只需看状态与结果，不以完整 GPUI 工具或深度 Alan 集成阻塞。正在核验公开数据源，当前未选择平台、未开始实现，本票保持 claimed。

候选数据核验已完成：[BTCUSDT 公开现货数据](../../../docs/research/public-spot-data.md)。官方明确公共行情域名无需 API key，本机历史 K 线与最优报价两次 REST 读取均 HTTP 200；尚未核验完整使用条款与长期运行。可优先 REST 轮询，避免首周引入完整盘口或 WebSocket 运维复杂度。用户选择仍待确认。
