# 一万元资金费率对冲机会测算

Type: research
Status: resolved
Assignee: codex
Parent: [量化验证路径地图](../map.md)
Blocked by: none

## Question

用户于 2026-10-19 授权先固定口径，用公开历史数据测算一万元扣除双腿交易成本、保证金和现金缓冲后的月度收益及不利情形，再判断是否值得进入模拟执行。

## Scope

[登记协议](../../../docs/research/funding-carry-protocol.json)：BTCUSDT 现货与等数量 USD-M 永续空头；2024/2025 全年与独立持有月诊断；40/40/20 资金占用、保守成本及清算风险代理为本轮研究假设，不是实盘授权或风险上限设定。保证金、缓冲不当作费用扣掉，头寸取整并计入真实可用资金。

## Answer

已完成[收益与风险测算](../../../docs/research/funding-carry-review.md)。初筛决定为 `do_not_enter_dual_leg_simulated_execution`。

2025 标准全年场内净收益估计 176.65 元；扣假设每边 0.5% 出入金损耗后为 76.01 元（标记价区间对应 75.32–76.66），最差月 -90.79 元。压力场景连出入金损耗也翻倍，全年约 -40.26 元；场内本身仍正收益，不能将它说成单纯交易费用使策略亏损。

2024 标准完整账面年收益约 633.98 元，但独立合约钱包触发预设保证金代理；即使资金费按上界，部分小时仍负余额，所以后续完整年度收入不能视为可拿到的钱。初始现金缓冲若及时全额转入，历史资金量可能足够，但时序和失败处理未经验证。

API HTTP451 在收益下载前已发现，事前修订协议并保存旧登记；没有绕过，改用公开档案及同小时 mark OHLC 构建有符号收支上下界，明确不能复原精确结算与真实强平。96 组 ZIP／校验和、8 项 Rust 测试、52 个期间与 35088 条年度小时数据的独立 Decimal 审计均通过。

数据、版本、净收益、月表与限制存入 `spikes/nautilus-trend/artifacts/history/btc-carry-v1`。未改既有 GUI 包／paper 账户或启动新模拟、定时任务与真实交易。费曼复述尚待用户回答，不代表学习已掌握。
