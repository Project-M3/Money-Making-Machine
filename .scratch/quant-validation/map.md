# M3 研究与工程决策地图

Labels: wayfinder:map

## Destination

建立符合个人资金属性、每周 6–10 小时投入节奏与能力圈优势的**芒格集中价值研究与决策工作台（Munger Workbench）**：以确定性 Rust 财务引擎从一手财报核算真实股东盈余与安全边际，以 Alan 跨学科审讯与逆向思维消除盲区，以安静高密度的 GPUI 桌面工作台支撑“等待好球、重仓少做”的长期投资与费曼式能力积累。

## Notes

- **2026-10-15 ~ 2026-10-19（第一阶段量化探索，已归档）**：按事前登记与独立审计完成了首条 `BTC/USDT` 1h SMA20 闭环、48h 常驻运行检验，以及历史回测（[05-sma20-history](issues/05-sma20-history.md)）和一万元资金费率对冲测算（[06-funding-carry](issues/06-funding-carry.md)）。两条短周期/套利假设均因成本、低收益与生活节奏错配而被客观否定，完整源码与证据归档于 `spikes/nautilus-trend/`。
- **2026-11-19（战略转向确认）**：用户系统反思并确认转向**查理·芒格价值投资范式**，明确四项核心决策：
  1. **聚焦范围**：第一版建设 **15–20 家能力圈深度观察台 + 查理计算器 + Alan 逆向审讯**；全市场 5000 股筛选器留待二期。
  2. **首批标的**：优先基于 SEC EDGAR 免费一手 XBRL 覆盖美股能力圈（`AAPL`、`GOOGL`、`ADSK`、`PTC`、`SNPS`、`COST` 与 `Too Hard` 样本 `INTC`），同时在统一架构中纳入欧股 `DSY.PA`（待录 IFRS 财报）与港股 `1810.HK`（`Too Hard` 样本）。
  3. **当前仓演进**：保留历史量化否定证据作为归档，将 `apps/m3-desktop`（Rust + GPUI 0.2.2 + `m3` JSON CLI）彻底重塑为 Munger Workbench。
  4. **预算与实盘边界**：首轮三个月、1 万元人民币预算定位为研究与数据费用上限，保持纯研究 + 模拟决策账本（不开户、不入金、不执行实盘）。
- **算术与推理分离铁律**：一切财报数值与估值算术由 Rust 确定性代码计算并带 SHA-256 溯源；Alan 只做跨学科定性审讯与事前验尸，严禁替代用户填写 `human_judgment` 或给出买卖建议。

## Decisions so far

- [确认投入边界与生活方式约束](issues/01-constraints.md)：三个月预算内研究自治与费曼式学习，每周 6–10 小时、不盯盘，全 Rust + GPUI，实盘与重要权限须用户确认。
- [固定 SMA20 的历史优势筛选](issues/05-sma20-history.md)：2024/2025 标准与压力成本均亏损，依预登记规则放弃并归档。
- [一万元资金费率对冲机会测算](issues/06-funding-carry.md)：2025 标准扣损耗年收益约 76 元且 2024 合约钱包保证金不足，不进入模拟执行并归档。
- **2026-11-19 芒格价值研究工作台转向（本次实施）**：重塑 `apps/m3-desktop` 为确定性 SEC XBRL + 查理计算器 + 4 视图 GPUI 工作台，建立 `workbench/` 观察池、审讯档案与模拟决策账本。

## Out of scope

- 券商开户、入金、交易密钥管理与真实下单接口。
- 全市场 5000 股跨准则清洗平台、实时逐笔行情与 K 线看盘软件。
- 由 AI 代替用户生成财务数字或替用户锁定投资信念与仓位决策。
