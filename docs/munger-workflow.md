# 芒格人机混动审讯工作流（Alan 与人类主理人协作协议）

本协议把查理·芒格的“能力圈过滤 + 跨学科格栅 + 逆向思维 + 击球纪律”固化为可重复的本地流程，并防止两类常见失效：**LLM 财务数字幻觉** 与 **AI 越权替代人类判断**。

---

## 第一阶段：确定性体检（Rust 引擎完成，零 LLM 介入）

在开始任何定性讨论之前，必须先由 `m3 sync` 与 `m3 report <TICKER>` 从一手官方财报产出确定性指标：

1. **投入资本回报率（ROIC）与稳定性**：近 5–8 年 ROIC 均值与标准差、毛利率稳定性。
2. **严苛股东盈余（Strict Owner Earnings）**：`经营现金流 (OCF) - 资本开支 (CapEx) - 股权激励费用 (SBC)`，不采信剔除 SBC 的口径。
3. **股权稀释 vs 逆向稀释**：3 年 / 5 年稀释股本净变化率，以及最新财年/季报期的回购与 SBC 对比。
4. **资产负债表安全度**：净负债（`总有息负债 - 现金及短期投资`）与严苛股东盈余之比（超过 3 倍标黄）。
5. **反向估值（Reverse Valuation）**：按 `总年化回报 ≈ 初始严苛 FCF 收益率 + 每股增长率`，由当前股价直接反推市场隐含的长期增长期待，对比用户的保守假设击球价。
6. **自动红黄灯预警**：例如最新季报期出现 `CapEx > OCF`、回购骤停、SBC 占 OCF 超 25%、或 5 年 ROIC < 15%。

---

## 第二阶段：Alan 跨学科审讯（生成 / 更新 `dossier` 草稿）

Alan 读取 `m3 report <TICKER>` 的确定性事实与 10-K/电话会原文，起草或刷新 `workbench/dossiers/<TICKER>.json` 的 AI 草稿区（`draft_source = "agent_draft"`）：

1. **能力圈三句话过滤（3-Sentence Business Filter）**
   - 用三句大白话说清：它卖什么给谁、为什么客户离不开/不找替代品、赚钱后的现金最后去了哪里？
   - 若三句话说不清，或商业未来高度依赖押注下一代爆品/价格战，建议归入 `Too Hard`。
2. **跨学科格栅透视（Latticework Mapping）**
   - **微观经济学**：护城河来源（转换成本 / 网络效应 / 规模成本 / 品牌特许权）及围攻力量。
   - **生态位与演化**：处于生态系统里的“造物主操作系统”还是“中立过路费收费站”？技术范式变迁时是受益者还是柯达式受害者？
   - **心理学与激励机制**：客户为何愿为之付费（芒格误判心理学）？管理层股权激励、KPI 与长期股东利益是否一致？
   - **资本配置史**：管理层拿到自由现金流后，是做高回报回购分红，还是做高溢价跨界并购（Diworsification）？
3. **逆向事前验尸（5-Year Pre-mortem）**
   - 假设 5 年后该股票永久性亏损 50% 以上或护城河瓦解，列出 3–4 条最具体、最致命的失败路径，逐一结合当前财报预警核对。
4. **开放质疑清单**
   - 给出需要用户本人查阅财报电话会或凭借行业经验拍板的 2–3 个核心分歧问题。

> **铁律**：Alan 在草稿中**禁止给出“建议买入 / 卖出 / 抄底”指令**，也**禁止替用户填写 `human_judgment`**。

---

## 第三阶段：人类主理人答辩与费曼防线（不可跳过）

公司若要进入 `core` 或触发 `PAPER_BUY` / `WAIT` 决策账本记录，必须由用户本人亲自回答并锁定 `human_judgment`：

1. **我的核心定性判词（`my_stance`）**：用你自己的语言复述这家公司的赚钱机器和护城河本质。
2. **核心权重判断（`weight_rationale`）**：对 Alan 列出的红黄灯（如 Google 2000 亿美元 AI CapEx 或软件股高 SBC），你判断它是“短期阵痛的超级收费站建设”还是“永久变重的吞金兽”？依据是什么？
3. **事前证伪指标（`falsification_metrics`）**：提前写下哪些客观财务或业务指标恶化时（如连续两年毛利率跌破 X%、CapEx/OCF 超标且云增速放缓至 Y% 以下），你必须承认判断错误并退出。
4. **费曼复述验证**：每周 1–2 小时学习时间里，由 Alan 针对你的 `human_judgment` 追问一个反例或做一次小计算，只有当你能不看提示独立讲透后，才标记 `feynman_checked_at`。

---

## 第四阶段：安静等待与决策账本

- 平时不盯日内涨跌。只有当价格跌入预设**击球价（Strike Price）**、或者季度财报亮起新的红黄灯时，再打开 GPUI 工作台重新审视。
- 所有重要决定（无论归入 `Too Hard`、继续 `WAIT` 还是执行 `PAPER_BUY`）都通过 `m3 journal record` 冻结当时的价格、严苛 FCF 收益率与理由，并与“100% 现金”和“标普 500 指数（`^GSPC`）”长期对照。
