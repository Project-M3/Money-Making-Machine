# 一万元 BTC 资金费率对冲：经济性测算

**结论：本版本不进入自动双腿模拟执行。** 在固定资金分配下，2025 年持续持有的场内净收益估计约 **176.65 元**；再扣本轮假设的人民币出入金损耗，全年约 **76.01 元**。双倍综合成本情景为 **-40.26 元**。2024 年还暴露了独立合约钱包的资金不足，即使组合总净值看起来平稳，也不能保证空头腿一直持有。

这是对登记假设的历史测算，不是实际账户收益或未来收入承诺。资金费精确结算 API 在本机返回 HTTP 451，未绕过访问限制；本轮改用公开档案，给资金费与净收益同时计算上下界。实际出入金渠道成本、账户准入和历史维护保证金未核实，因此不能称为可直接落地的净收益报价。

## 固定口径与证据顺序

2026-10-19 用户授权后先登记[测算协议](funding-carry-protocol.json)，再下载资金费数值。在任何收益计算前发现 API 访问限制，保留首次登记并补充登记公开档案／标记价区间方法与数量步长假设；不是看完结果后改口径。最终协议 SHA-256 为 `b17ef04aea7514c3b7a4235b001a06265734fd2c290eaeb88e76286cabec4b0e`。测试通过后冻结 Rust 源码、二进制和独立审计，再一次性计算完整 2024、2025 年，没有挑选正费率月份或搜索资金分配。

| 项目 | 本轮研究假设 |
| --- | --- |
| 总本金 | 人民币 10000 元，全部收益率分母为总本金 |
| 计价转换 | 固定 7.20 元／USDT，只用于换算，不是当前汇率或兑付保证 |
| 资金配置 | 转入后 40% 现货预算、40% 独立 USDT 合约抵押、20% 现金缓冲；不借币／借钱，不将现货浮盈自动当合约可用保证金 |
| 头寸 | 买现货、做空相同 BTC 数量，全年数量固定，不复利、不择时；按研究假设 0.001 BTC 步长向下取整，同时满足现货开仓费用和合约初始足额抵押预算 |
| 缓冲 | 主路径不自动转账；另测“全部初始现金缓冲能及时加入合约钱包”的资金充分性诊断，不把它当已实现的调拨规则 |
| 标准成本 | 现货每边 10bp、永续每边 5bp 手续费；两腿各边 5bp 不利滑点；出入金各 50bp 损耗情景 |
| 压力成本 | 上述手续费、滑点、出入金损耗均翻倍；它是双倍综合成本，不只是双腿交易费翻倍 |
| 持有／退出 | 年初两腿开仓，年末两腿平仓估值；每小时净值包含届时双腿退出成本。收益不分配到新仓位 |
| 月度展示 | 连续年度账户的月末净值变化；另做每个月独立从一万元开平仓的诊断，不能拼成可实现收入或自动补足亏损本金 |
| 保证金诊断 | 逐小时标记价收盘及保守小时最高价检查独立空头钱包；采用名义价值 2% 的研究代理阈值，不是真实历史维保档位或强平价 |

费用是未享受折扣的模型假设，不是用户实际费率。出入金每边 0.5%／1% 是敏感性假设，未找到并报价一个可用人民币渠道，不能当市场收费事实。报告同时给出不含出入金成本的相同数量结果，避免将交易经济性和渠道成本混淆。[官方机制、数据、费用与限制核验](funding-carry-data.md)

标准情景中，扣入金损耗后有 **9950 元**可分配：现货预算 3980、合约抵押 3980、现金缓冲 1990。保证金和缓冲都是本金的一部分，**没有再次作为费用减去**。2025 年由于数量取整，只持有及对冲 0.005 BTC，起点现货名义价值约 **3368.74 元**；现货预算中约 606.21 元保持现金。2024 年为 0.013 BTC、约 3957.74 元。没有把一万元全部当作可收资金费的名义头寸。

所有金额为人民币估计值。*2024 主路径发生保证金诊断失败，表中完整年度收入是允许空头继续存在的理论账本，**不能作为该路径可拿到的收入**；不会平均两个年度来宣传年收益。

资金费估计收入       +192.4941
现货／永续价差损益     +0.4615

对应总本金的约 **0.7601%**，全年平均约 **6.33 元／月**，不是每月固定到账。不含出入金损耗的约 176.65 元约为每月 14.72 元。压力情景场内仍赚约 160.34 元，变成整体亏损主要因为假设的往返出入金损耗升至约 200.60 元；不能把这个结果说成仅仅交易手续费翻倍就使其亏损。

2024 标准情景的理论入金／出金损耗共 103.44 元；2025 标准为 100.63 元。本轮没有额外购买云服务或交易工具，也没有将已有 Agent 订阅摊成新增费用。现金对照按零收益的一万元现金，不假设未核实的存款或其他产品利息。

### 资金费估计误差区间

公开归档含 `calc_time`、`funding_interval_hours`、`last_funding_rate`，不含精确结算标记价。本轮按这些时间／费率作为历史结算序列，使用同小时标记价开盘估计，每笔按标记价最低／最高价计算收支上下界；费率为负时反转上下界。保留全部负费率，不根据后来费率决定是否入场。

| 年度／情景 | 净收益下界 | 开盘标记价估计 | 净收益上界 |
| --- | ---: | ---: | ---: |
| 2024／标准（理论） | 630.44 | 633.98 | 637.59 |
| 2024／压力（理论） | 442.58 | 445.84 | 449.15 |
| 2025／标准 | 75.32 | 76.01 | 76.66 |
| 2025／压力 | -40.95 | -40.26 | -39.62 |

这些上下界以档案完整、小时标记价区间可靠、归档费率代表结算费率为条件，不能取代 API 交叉验证或真实到账记录。本轮的区间宽度不会改变成本与资金占用的初筛结论，但未来仍可能出现档案修订、价格偏离、费率或结算机制变化。

### 多久覆盖成本

事后看，标准持续路径的累计估计资金费首次覆盖模型四笔交易成本约需 **2024 年 19.67 天、2025 年 20.33 天**；压力路径约 47.33／46 天。这个指标不含出入金损耗和价差损益，并用了最终模型退出成本，只是事后归因，不是入场时已知的回本预测。

完整人民币净清算值首次回到一万元，标准路径约需 **2024 年 61.96 天、2025 年 225.54 天**；2025 压力路径整年没有回本。首次回本以后仍可能再次亏损。上述时间不是将当前费率乘成年化得到的承诺。

## 最差会怎样：总净值与合约钱包必须分开看

### 历史内已经暴露的资金约束

2024 标准路径在 **11 月 12 日 07:00（Asia/Shanghai）**首次触及 2% 的独立合约钱包代理阈值。到 11 月 13 日 22:00，连采用对收入有利的资金费上界，某些小时收盘的合约钱包也会为负；其最差小时的上界余额约 **-1463.43 元**。压力路径同样不足。

原因是 BTC 上涨时，现货腿赚的钱在现货钱包，空头腿的损失先消耗合约钱包。初始足额抵押不等于未来价格上涨后仍一直足额；两腿总和接近对冲，并不保证合约钱包可支付亏损。

若假设整个初始 1990 元现金缓冲都能及时转入合约钱包，2024 标准历史内的最小保守保证金比例约为 **5.05%**，没有再触及本轮 2% 代理。这表明**现有预算中的缓冲可能够用**，并不一定需要追加本金；但尚未定义或验证转入时机、转账延迟、失败、休眠及异常处理，所以不能把这个资金充分性诊断当成执行已解决。本轮也未将约 16.32 元剩余现货预算自动挪用到合约钱包。

2025 标准路径未触及代理阈值，小时内保守最小比例约 65.12%；这只说明该年度、该起点和模型路径未暴露同样问题。2% 是研究假设，不是真实维保率；没有历史账户档位和逐笔标记价，不能报出某个“真实强平时刻／损失”。

### 历史净值回撤

2025 标准小时收盘清算净值最大回撤约 **117.16 元（初始本金的 1.17%）**；压力约 **233.00 元（2.33%）**。2024 理论组合的回撤约 123.67 元，**但组合回撤小没有阻止独立合约钱包先出现问题**。小时内极值组合只作保守区间诊断，不冒充真实同步成交或盘中最大回撤。

### 合成压力，不是未来最大损失

以 2025 标准起点头寸为例：

| 情形 | 额外影响／诊断 |
| --- | --- |
| 连续 30 天每 8 小时支付 1bp 资金费 | 约再损失 30.31 元，未含交易或价差损失 |
| 永续相对现货的价格差扩大 5 个百分点 | 对冲组合约损失 168.39 元；属于合成情景 |
| 两边价格都从起点翻倍 | 组合方向敞口仍接近对冲，独立空头钱包约余 608.88 元；2024 起点则仅约余 15.45 元，可能早于归零触发真实维保要求 |
| 转账来不及或只成交一条腿 | 本轮未恢复逐笔时序，损失不由上述对冲收益区间约束；不能假定能立即平仓 |
| 平台或托管失效 | 假定资金与缓冲均在平台，可能损失接近全部一万元；历史低回撤不能给它定价或排除它 |

因此，“最差月约亏 91 元”不是“最多只亏 91 元”，也不是最大损失边界。额外稳定币和人民币汇率变化未由固定 7.20 换算覆盖。

## 是否进入模拟执行

预登记要求两个完整年度在标准和压力下的资金费下界净收益均为正，且主路径不触及保证金代理阈值，才考虑报价级模拟。结果两项均未满足：2025 压力综合成本后仍为负，2024 独立钱包存在资金约束。

据此，**不为本固定 BTC 对冲持有版本建设或启用自动双腿执行**。它有可解释的资金费来源，但在一万元规模、保守资金占用和成本假设下收入很薄，需要处理的调拨、非同步成交与平台风险并未随金额变小而消失。若已持有可用 USDT、真实兑换损耗显著更低，场内收益会较好；也仍不能把每月约十几元的历史平均直接当作值得开发的收入业务。

本轮没有顺手提高资金利用率、缩小保证金、追逐其他高费率币、搜索入场时机或启用新策略。任何更高利用率／调拨规则都需要新的协议和压力检验；不以加大风险来填补低收益。

## 实现、复现与保留的证据

新增 [Rust 经济测算入口](../../spikes/nautilus-trend/src/carry.rs)，同一 crate 复用既有十进制、价格精度和 CLI 入口；本轮是资金账本，不调用交易所订单接口，也不把它说成原生双腿撮合验收。没有新 Cargo 依赖。8 项 Rust 测试通过；独立 Python Decimal 对 **52 个期间账本和 35088 条年度小时净值**、资金费上下界、保证金、费用、回撤、分月变化逐项比较通过。

产物根目录：`spikes/nautilus-trend/artifacts/history/btc-carry-v1/`。

- `registration.json`、`registration-data-limit.json`、`implementation-freeze.json`：初次登记、API 限制下的事前协议修订、实现与二进制摘要。
- `sources/`、`data-manifest.json`：96 组官方 ZIP／CHECKSUM，分别为两个完整年度的现货价格、永续成交价格、标记价格、资金费月归档；SHA-256、CSV 哈希、原文与数据条款均保留。一次连接失败后重试，已有数据校验后复用，未替换数据源。
- `input-2024.json`、`input-2025.json`：8784／8760 条小时价格，1098／1095 条归档资金费记录；入场边界首分钟结算不计为已持有收入。2025 现货微秒按原小时边界转换为毫秒，保留原 ZIP。字段、单位、连续性、月份范围与资金费间隔均检查。
- `2024/`、`2025/`：标准和压力的全年小时净值、月度变化、独立月度测算、收益区间与保证金诊断。
- `independent-audit.json`、`audit.py`：独立核账与可检查的参考计算。
- `wallet-and-cost-diagnostics.json`、`research-result.json`：资金钱包及成本分解、供 Agent 使用的结论与限制。

本轮未绕过 451、未用历史小时开盘标记价冒充精确结算标记价，也未用当前规则冒充历史清算档位。公开档案在当前条款下用于个人非生产研究，准入、实盘与商业复用另行核实。[数据来源及许可](funding-carry-data.md)
